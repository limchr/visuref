VisArt.app is an interactive art studying website. It focusses on the main narrative 'How can I see what really is?' a key question that distinguishes a good from a bad artist. It is really independent from the actual art medium, wether it is pencil drawings, acrylic, oil, watercolor or anything else.

The concept of the website is:

1. A tool for visualizing and editing reference images for drawing and painting purposes. The user can 1. upload an image or 2. select an image from a reference gallery. The user can then enable different modules in an image processing pipeline. There are modules for changing the contrast, saturation, greyscale, brightness, crop, color palette, grid overlay and more in the future.

Future Tools: 
- Draw in shapes like triangles, cones, rectangles, circles, lines
- Flip image / rotate image 180 deg

2. There are free courses, each consist of multiple lectures. The lectures are acessible for free and the user can read about how to draw/paint and the course further links to the app for demonstrate certain concepts and to advertise it and user engagement and further experimentation using different settings / reference images.


I thought about a course structure like:

1. The main challenge of any visual artist

- Narrative of this website: The importance of observation and “learning to see.”
- Show an angled face and how it translates in our mind to a symbol. make sense cognitively but not from an art perspective
- not only in photorealistic art: We want to express what really is in our mind and not only the concepts our cognitive mind is working with. From lucky accidents towards control of our vision

- Explain app and course structure. Comment section and sharing of results. 

2. Composition and Measuring

- Measuring proportions with measure tool: forshortening in body poses
- grid view for landscape painting
- face painting: flipping the face upside down for breaking the concept in your mind

Excercise: compose certain image in gallery with the right composition, any art style is allowed. Post your result and mention which of the mentioned techniques you used.

3. Light, Shadow & Value
- Concept of Light and Value: When we see a face, one light source - our brain nows that the skin color is the same for both sides of the face. It completely neglects that one side is dark and the other side is very bright. It can not even access the real value, you have to actively think about that.

- Step back: basic sphere, one light source (shadow, drop shadow, reflection from lower surface)

- Black and white tool

- Excercice: draw the sphere as acurate as you can, drop your image in the comment section for discussion

4. Light, Shadow & Value 2

- Multiple objects

- Value scale (from light to dark) (greyscale and palette tool)
- Techniques: hatching, cross-hatching, blending, stippling.
- Contrast and composition: how values guide the eye.
- Exercises: draw spheres, cylinders, and cubes with light and shadow (all in reference gallery)

5. Light, Shadow & Value 2

Use Filter and Palette Tool for simplifying real images

6. Studying old masters
 - maybe even with Peter
Studying from references and masters (change parameters of the reference image to explore the 'real' values)
Experimenting with abstraction, exaggeration, and stylization (change number of colors in palette module to see how the complexity of the image changes when adding more distinct colors).
